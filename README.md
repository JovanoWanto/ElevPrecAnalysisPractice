# ElevPrecAnalysisPractice
Scatterplot displaying the relationship between elevation and precipitation using GeoTIFF data. This is a personal exercise in geospatial data analysis and visualization using raster maps.

Data Source:
 -Precipitation: https://www.worldclim.org/data/worldclim21.html
 -Elevation: https://asterweb.jpl.nasa.gov/gdem.asp

Tools used:
 -QGIS
 -GRASS GIS
 -Libreoffice
